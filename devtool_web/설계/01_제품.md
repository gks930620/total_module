# 01. 제품 — 무엇을 · 누구에게 · 어떤 규칙으로

> **지금의 제품**만 적는다. 변경 이력은 남기지 않는다.
> 무엇이 있는지: `03_도구카탈로그.md` · 왜 저건 없는지: `04_미구현.md`

## 1. 한 줄 정의

**데이터 형식 변환부터 ERD·이미지·PDF 편집까지 웹 도구 37종을,
광고 없이 · 가입 없이 · 완전 한국어로 · 파일을 서버에 올리지 않고 제공하는 도구 모음.**

## 2. 풀려는 문제

| # | 문제 | 기존 대안의 한계 |
|---|---|---|
| P1 | JSON 응답 확인·포매팅을 매일 하는데 수 MB급에서 브라우저가 멈춘다 | 해외 포매터는 대용량에 취약 + 광고 과다 |
| P2 | **붙여넣은 데이터가 서버로 가는지 알 수 없다** — 사내 API 응답·토큰·개인정보를 외부 사이트에 넣기 불안하다 | 대부분 처리 위치를 명시하지 않는다 |
| P3 | 이력서 PDF·가족사진을 낯선 사이트에 **업로드**해야 편집할 수 있다 | 업로드가 표준 관행이 돼 버렸다 |
| P4 | 영문 도구는 한국 실무와 안 맞는다 | 평·근·돈 단위, 원화 한글 표기, 주민번호·계좌번호 형식, KST 기준 |

## 3. 핵심 가치 — 세 가지

1. **업로드가 없다.** 37종 전부 브라우저 안에서만 동작한다. 애초에 입력을 받는 서버 API가 존재하지 않는다.
2. **광고·추적·가입이 없다.** 그래서 어떤 도구가 인기 있는지 우리도 모른다 — 감수하기로 한 비용이다.
3. **한국 실무 기준이다.** 완전 한국어 UI, KST 기준 시간 계산, 한국 단위·표기·형식 규칙 내장.

> P2·P3 는 마케팅 문구가 아니라 **구조적 사실**이다. 서버에 받을 엔드포인트가 0개다.
> 이 약속은 예외가 하나만 생겨도 무너지므로, 서버가 필요한 기능은 아무리 유용해도 넣지 않는다(→ `04_미구현.md`).

## 4. 타깃

| 순위 | 대상 | 주로 쓰는 도구 |
|---|---|---|
| 1차 | 한국 백엔드·프론트 개발자 | JSON · JWT · 정규식 · cron · CIDR · cURL 변환 · **ERD·클래스 다이어그램** |
| 2차 | QA · 기획 · 마케터 | 목록 비교 · 더미데이터 · UTM · OG 미리보기 · 글자수 · **순서도** |
| 3차 | 일반 사용자 | 글자수 · 이미지 리사이즈 · PDF 편집 · 날짜/단위/대출 계산 · 추첨 |

3차는 원래 범위 밖이었으나, "업로드 없이 처리한다"는 강점이 개발자보다 **일반 사용자에게 더 크게 작동한다**고
보고 포함했다(사진 위치정보 제거·PDF 편집이 대표적).

## 5. 수익 모델

**없다.** 광고·유료 플랜·회원가입을 도입하지 않는다. 운영비는 Railway 단일 인스턴스 비용뿐이다.

## 6. SEO 전략

검색 유입이 유일한 획득 경로다.

- **도구마다 개별 URL** (`/convert`, `/pdf`, `/erd` …) + 개별 `<title>`·description·keywords
- 각 페이지 하단에 **사용법 정적 블록** — 화면 그림 · 넣는 값과 나오는 값 · 짧은 설명
- `sitemap.xml`(42개 URL) · `robots.txt` 제출
- 노리는 검색어: "글자수 세기", "이미지 크기 줄이기", "pdf 합치기", "ERD 그리기",
  "평 제곱미터 변환", "대출 이자 계산기" 등 — **한국어 실무 표현** 위주

## 7. 성공 기준

출시 90일 후 평가한다.

| 지표 | 기준 |
|---|---|
| 월 순방문자(UV) | 5,000 이상 → v2 확장 검토 / 1,000 미만 → 유지 모드 |
| 검색 유입 비중 | 60% 이상 |
| 도구별 편중 | 상위 3개가 전체의 80%를 넘으면 나머지 정리 검토 |

> ⚠️ 추적을 하지 않으므로 이 수치는 **Railway 접속 로그와 서치콘솔**로만 본다. 사용자 단위 분석은 불가능하다.

## 8. 리스크

| # | 리스크 | 대응 |
|---|---|---|
| R1 | 검색 유입이 안 붙는다 | 도구별 URL·사용법 블록·sitemap 이 이미 준비됨. 3개월 후 키워드 재조정 |
| R2 | 대용량 JSON 에서 실제로 멈춘다 | Web Worker 파싱 + 트리 가상 스크롤. 배포 후 5MB/20MB 실측 필요 |
| R3 | 도구가 37종이라 뭐가 있는지 안 보인다 | 그룹 7개 + 홈 히어로 검색(개념 태그) + 카드 그리드 |
| R4 | 브라우저 처리 한계(대용량 이미지·PDF)에서 탭이 버거워진다 | 각 도구에 권장 한도를 사용법 블록으로 안내 |
| R5 | "업로드 없음"을 사용자가 안 믿는다 | 개발자도구 네트워크 탭으로 검증 가능함을 사용법 블록에 안내 · CSP `connect-src 'none'` 이 강제 |

# 공통 규칙

여기부터는 **모든 도구에 공통으로 적용되는 규칙**이다. 도구별 기능 명세는 두지 않는다 —
37종 전수는 `03_도구카탈로그.md` 가 단일 기준이고, 코드상 단일 출처는 `frontend/src/lib/tools.js` 다.

## 9. 공통 기능 (COM)

| ID | 요구사항 | 상태 |
|---|---|---|
| COM-01 | 홈: 그룹별 도구 카드 그리드 (이름·한 줄 설명·아이콘) | ✅ |
| COM-02 | 도구별 개별 URL + 개별 title/description/keywords/canonical | ✅ |
| COM-03 | 홈 히어로 검색 — 이름·개념 어느 쪽으로 쳐도 찾는다 | ✅ |
| COM-04 | 전 도구 하단 사용법 정적 블록 — 화면 그림·예시·설명 (SEO 콘텐츠) | ✅ |
| COM-05 | 결과 원클릭 클립보드 복사 | ✅ |
| COM-06 | 설정을 localStorage 에 저장 (`02_구조.md` §5) | ✅ |
| COM-07 | 다크 모드 — 라이트·다크 **2단** 토글. 고른 적 없으면 OS 설정을 초기값으로 | ✅ |
| COM-08 | sitemap.xml · robots.txt · OG 태그 | ✅ |

> 예전에 있던 "서버 전송 없음" 배지와 "최근 사용" 목록은 걷어냈다.
> 배지는 모든 화면에 같은 문장을 반복해 오히려 눈에 안 들어왔다. 사이드바도 함께 걷어냈다 —
> 본문이 폭을 다 쓰고, 찾는 일은 홈 검색이 맡는다.
> 약속 자체는 CSP `connect-src 'none'` 과 사용법 블록으로 지킨다.

## 11. 도구를 새로 추가할 때

1. **클라이언트 사이드 100%** — 서버 API 가 필요한 기능은 넣지 않는다(NFR-02). 협상 대상이 아니다.
2. **외부 라이브러리는 senior-dev 결정 사항** — gzip 200KB 상한(NFR-04).
   무거운 것은 **동적 `import()` 로 격리**하면 도입 가능하다. 선례가 둘 있다.
   - `pdf-lib` — `/pdf` 사용자에게만 전송
   - `mermaid` — 다이어그램 6종에만. gzip 950KB 지만 종류별로 갈라져 **쓰는 것만** 내려온다(`05_다이어그램.md`)
3. **로직은 `lib/*.js` 순수 함수로 분리하고 테스트를 먼저 쓴다** — TDD 가 이 프로젝트의 규칙이다.
   페이지 컴포넌트에는 상태·입력·표시만 둔다.
4. **라우트는 5곳을 함께 고친다**
   `lib/tools.js` → `App.jsx` → `HomeController` → `SecurityConfig` → `public/sitemap.xml`
   백엔드 두 곳이 어긋나면 **운영에서만** 403 이 난다(로컬 재현 안 됨).
   세 테스트가 잠근다 — `lib/__tests__/tools.test.js` · `guides.test.js`(각각 5곳 전수 대조) ·
   `SpaRouteApiIntegrationTest`(실제 forward 확인).
5. **제안 전에 `04_미구현.md` 를 먼저 읽는다** — 이미 검토하고 기각한 항목일 수 있다.
6. **화면은 J "헤일로" 토큰만 조합해 만든다** — 색·그림자·둥글기를 하드코딩하지 않는다(`02_구조.md` §6).

## 12. NFR-02 실측 방법

주장이 아니라 검증 가능한 사실로 유지한다. 배포 전마다 확인한다.

| 검사 | 통과 기준 |
|---|---|
| 소스에서 `fetch(` · `XMLHttpRequest` · `axios` · `sendBeacon` · `new WebSocket` 검색 | **0건** (`/curl` 이 *출력하는 문자열*은 제외) |
| 서버 엔드포인트 | `/healthz` · actuator · SPA forward 외 **0개** |
| localStorage 키 | `dtb.settings` · `dtb.schema_version` + `dtb.canvas.*`(그리기 문서 — 사용자가 그린 도형·좌표) |
| 브라우저 네트워크 탭 (도구 사용 중) | **0건** |

> Material Icons 는 `public/fonts/` 로 옮겨 직접 서빙한다. 이게 앱 전체의 마지막 외부 요청이었고,
> 없앤 덕분에 CSP 에 `connect-src 'none'` 을 걸 수 있게 됐다 — 약속을 문장이 아니라 **브라우저가 강제**한다.
