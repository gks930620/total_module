## 어떤 일을 할 때 어디를 보나

| 하려는 일 | 볼 곳 |
|---|---|
| 새 도구를 만든다 | **04**(이미 기각됐나) → **01 §11**(지켜야 할 것) → **02 §4**(라우트 5곳) |
| 화면을 손본다 | **02 §6** — 토큰만 조합한다. `#hex` 를 쓰고 싶으면 토큰을 먼저 늘린다 |
| 지금 뭐가 있나 궁금하다 | **03** (단일 출처는 코드 `frontend/src/lib/tools.js`) |
| 배포한다 | **02 §8** + [07_배포_Railway.md](07_배포_Railway.md) |
| 라이브러리를 넣고 싶다 | **01 §11-2** — 동적 `import()` 로 격리하면 가능하다 |
