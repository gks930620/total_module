# 02. 구조 — 아키텍처 · 화면 · 저장

> 지금의 구조만 적는다. **서버 API 0개 / 데이터베이스 0개.**
> 도구별 상세는 여기 두지 않는다 — 37종 전수는 `03_도구카탈로그.md` 가 관리한다.

---

## 1. 전체 구조

```
브라우저                                    Railway 컨테이너 1개
┌────────────────────────────┐            ┌──────────────────────────┐
│  React SPA (도구 37종)       │            │  Spring Boot 3.3.4        │
│   · 모든 계산·변환·파일 처리   │ ←파일만──  │   · 정적 서빙 (static/)    │
│   · Canvas / WebCrypto      │            │   · GET /healthz          │
│   · pdf-lib · mermaid       │            │   · 그 외 전부 403         │
│     (둘 다 동적 로딩)         │            │                          │
│   · localStorage (dtb.*)    │            │                          │
└────────────────────────────┘            └──────────────────────────┘
        ↑ 여기서 모든 일이 일어난다              ↑ 파일을 내려주는 것이 전부
```

**서버로 나가는 요청은 정적 파일 다운로드뿐이다.** 도구를 쓰는 동안에는 아무것도 오가지 않는다.

## 2. 백엔드 (Spring Boot)

클래스 **5개**가 전부다.

| 클래스 | 역할 |
|---|---|
| `DevToolboxApplication` | 진입점 |
| `HomeController` | 라우트 42개를 `forward:/index.html` 로 넘긴다(SPA 새로고침·직접 접속 대응) |
| `common/web/HealthController` | `GET /healthz` → `200 {"status":"UP"}` |
| `common/config/SecurityConfig` | 화이트리스트 + `denyAll`. CSP·보안 헤더, 무상태 |
| `common/config/RailwayDeploymentValidator` | 운영 기동 시 `APP_PUBLIC_BASE_URL` 검증 → 없으면 **fail-fast** |

### 엔드포인트 전부

| 경로 | 응답 |
|---|---|
| `GET /healthz` | `200 {"status":"UP"}` |

| **그 외 전부** | **403** (`denyAll`) |

(+ Lombok, devtools)

## 3. 프론트엔드 (React 19 + Vite)

```
frontend/src/
  lib/            순수 함수 41개 모듈 — DOM·React 무관. 여기에 모든 로직이 있다
  lib/diagram/    다이어그램 파서·변환기 3개 (05 문서)
  lib/__tests__/  930건 / 44파일
  pages/          도구 페이지 48개 — 상태·입력·표시만
  components/     공통 7개
  workers/        정규식 워커 1개 — ReDoS 를 terminate() 로만 끊을 수 있어서 분리했다
  styles.css / styles-tools.css   J 헤일로 토큰 + 컴포넌트
```

**로직을 lib 으로 뺀 이유**: 계산이 컴포넌트 안에 있으면 테스트에 렌더링 환경(jsdom)이 필요하다.
순수 함수면 Node 에서 그냥 호출해 검증할 수 있다 — 그래서 930건이 몇 초 안에 돈다.

### 코드 분할

도구 페이지를 전부 `React.lazy` 로 분리했다. 첫 진입은 홈에 필요한 것만 받는다.

| | 값 |
|---|---|
| 첫 진입 (gzip) | **JS 63.5KB + CSS 9.3KB = 72.8KB** (상한 200KB) |
| 도구 페이지 청크 | 대부분 1~4KB, 진입 시에만 |
| `pdf-lib` 청크 | 178KB — `/pdf` 에서 실제 작업 시작 시에만 |
| `mermaid` 청크 | 종류별 35개로 갈라짐(합계 262KB) — **쓰는 다이어그램만** |

### 브라우저 API 활용

라이브러리 대신 내장 API 를 쓴다 — 번들이 늘지 않고 검증된 구현이라 안전하다.

| 용도 | 사용 |
|---|---|
| 이미지 처리 | Canvas 2D (`createImageBitmap`, `toBlob`) |
| 해시·서명 | WebCrypto (`SubtleCrypto`) — SHA 계열, HMAC, RSA, ECDSA |
| 난수 | `crypto.getRandomValues` (CSPRNG). `Math.random` 안 씀 |
| 시간대·정렬 | `Intl.DateTimeFormat` · `Intl.Collator("ko")` · `Intl.Segmenter` |
| 대용량 JSON · 정규식 | Web Worker |
| PDF · 다이어그램 | **`pdf-lib`** · **`mermaid`** — 외부 런타임 의존성은 이 둘뿐, 동적 로딩 |

## 5. 저장 — localStorage 가 전부다

**서버에 저장하는 데이터가 없다.** 데이터베이스도, 서버 API 도 없다.

| # | 원칙 | 근거 |
|---|---|---|
| 1 | **도구 입력값은 어디에도 저장하지 않는다** — 서버·localStorage 모두 | NFR-02/03 |
| 2 | 설정만 localStorage | 계정 없이 재방문 UX |
| 3 | 저장 실패(시크릿 모드 등)여도 기능은 정상 동작해야 한다 | 저장은 부가 기능일 뿐 |
| 4 | 사용자·계정·세션 개념이 없다 | 제품 원칙 "가입 없음" |

**절대 저장하지 않는 것**: JSON 원문 · 주민번호 · 계좌번호 · JWT · 비밀번호 · 정규식 문자열 ·
이미지/PDF 파일 · 그 밖의 모든 도구 입력. 파일은 메모리에서만 다루고 끝난다.

네임스페이스 접두사 `dtb.` 고정. 설정 키(`lib/storage.js`)는 둘이고,
그리기 편집기가 `dtb.canvas.<종류>` 에 그린 문서를 자동 저장한다(도형·좌표뿐 — 도구 입력 원문이 아니다).

### `dtb.settings`

```json
{ "theme": null, "json_indent": 2 }
```

| 키 | 값 | 쓰는 곳 |
|---|---|---|
| `theme` | `null`(안 고름) \| `light` \| `dark` | 헤더 테마 토글 (`lib/theme.js`) |
| `json_indent` | `2` \| `4` \| `0` | `/convert` 의 JSON 들여쓰기 (`0` 은 한 줄) |

> `theme` 의 기본값 `null` 은 **아직 고른 적 없음**이고 **반드시 falsy 여야 한다.**
> `initTheme` 이 이 값으로 "OS 설정을 따라갈지" 를 판단하기 때문이다. 여기에 `"system"` 같은
> 문자열이 들어가면 그 분기가 조용히 죽는다 — 실제로 그랬고, `__tests__/theme.test.js` 가 잠근다.

### `dtb.schema_version`

현재 `"1"`. 위 키의 구조를 바꾸면 올리고, 읽을 때 마이그레이션하거나 초기화한다.

**새 키를 추가하려면 이 문서를 먼저 고친다.** `storage.js` 외의 파일에서 `localStorage` 를 직접 부르지 않는다.

## 6. 화면 · 디자인 시스템

UI 의 단일 출처는 `frontend/src/styles.css` 의 `:root` 토큰이다(목업 HTML 이 아니다).

```
┌─ 헤더 (유리, 따라다니지 않음) ────────── 로고 · 테마 토글 ─┐
├─ 본문 (content-area, 폭 1140px) ─────────────────────────┤
│  [홈]    히어로 + 검색 + 그룹별 카드 그리드                  │
│  [도구]  도구 헤더 + 툴바 + 작업영역 + 결과 + 사용법          │
└──────────────────────────────────────────────────────────┘
└─ 푸터 (내용은 아직 비어 있다) ────────────────────────────┘
```

- **헤더는 데스크톱에서 따라다니지 않는다**(`position: static`). 도구를 쓰는 동안 로고와 테마 버튼이
  자리를 차지할 이유가 없어서다. 모바일에서만 `sticky` — 로고가 홈으로 가는 유일한 길이라
- 검색은 **홈 히어로 한 곳**에만 있다(`lib/search.js` 의 `searchGrouped`).
  검색은 **점수를 매긴다**: 이름 > 슬러그 > 요약 > SEO 키워드 > 개념 태그.
  `tools.js` 의 `TAGS` 에 "인증"·"자소서"·"방화벽" 처럼 **도구 이름이 아닌 말**을 넉넉히 넣어 두고,
  순위로 정확도를 지킨다 — 순위가 없으면 태그를 늘릴수록 검색이 나빠진다
- 도구·문서 페이지는 전부 `React.lazy` 분할. **Suspense 경계는 `ToolboxLayout` 의 `<main>` 안**이다

### 도구 페이지 공통 패턴

37종이 전부 **"입력 → 변환 → 결과"** 단일 패턴이고, 배치는 **넣는 것은 왼쪽 · 나온 것은 오른쪽**이다.
그래서 화면 정의서를 도구마다 쓰지 않는다.

```
ToolHeader   아이콘 배지 + 제목 + 설명
toolbar      모드 칩 · 옵션 · 주 버튼(화면당 1~2개)
작업 영역     입력(area/input/dropzone) → 결과(kv-card/data-table/canvas/count-grid)
statusbar    처리 결과 요약 (개수·크기·시간)
ToolGuide    사용법 — 화면 그림(SVG) · 넣는 값→나오는 값 · 짧은 설명
```

### 시안 J "헤일로" — 화려함을 한 곳에 모은다

| # | 원칙 | 구체적으로 |
|:--:|---|---|
| ① | **읽는 면은 불투명** | 카드·패널·본문은 `--surface` 불투명. 유리·그라디언트 금지 |
| ② | **그라디언트는 초점에만** | 히어로(페이지당 1) · 주 버튼(화면당 1~2) · 아이콘 배지 · 선택된 칩 |
| ③ | **유리(blur)는 헤더에만** | 콘텐츠가 실제로 뒤로 지나가는 유일한 자리 |
| ④ | **카드 윗변 1px 그라디언트 선** | 평소 `opacity .16` → hover `.85`. 좌우를 16px 씩 띄운다 |

> 판단 기준: 한 화면에 그라디언트가 **3~5개면 적당, 8개 넘으면 실패**다.
> 시안 10개를 3라운드로 검토해 확정했다. 탈락 사유는 `디자인시안/디자인_결정기록.md`.

| 항목 | 값 |
|---|---|
| 카드·패널 둥글기 | `--radius` 20px |
| 입력창·작은 요소 | `--radius-sm` 13px |
| 버튼·칩·배지 | **999px (알약)** — 예외 없음 |
| 본문 | 14.5px / line-height 1.65 |
| 페이지 제목 | 25px / weight 750 / letter-spacing −.025em |
| 최대 폭 | 본문 1140px (헤더·푸터도 같은 선) |
| 카드 그리드 | 3열 → 2열(1024px) → 1열(768px) |

**테두리 대신 그림자 — 다만 가장자리 한 줄은 남긴다.** 흰 면(`--surface`)과 페이지 배경(`--bg`)의
차이가 2% 뿐이라 그림자만으로는 카드가 어디서 끝나는지 보이지 않았다. 도구 페이지의 읽는 면
(패널·kv 카드·상태바 칩·사용법 카드)에는 `--edge` 한 줄을 두른다. `--edge` 는 `--muted2` 에서
뽑으므로 다크 모드를 따로 덮어쓰지 않아도 따라온다. `--border`(#eeedfa)는 표의 행 구분선처럼
배경 위가 아닌 곳에만 쓴다.

**다크 모드**: `:root[data-theme="dark"]` 에서 **토큰만 덮어쓰면** 전 화면이 따라온다.
컴포넌트 CSS 는 손대지 않는다. 다크에서 `--surface` 를 순수 검정으로 두지 않는다 —
그림자가 안 보여 카드가 평평해진다.

> 새 컴포넌트는 **토큰만 조합**해 만든다. `#hex` 를 쓰고 싶어지면 토큰이 부족한 것이니 토큰을 먼저 늘린다.
> 안 그러면 다크 모드가 그 컴포넌트에서만 깨진다 — 실제로 `--warn-soft` 를 안 만들어 두 곳이 그랬다.

## 7. 브라우저에 강제시키는 것 (CSP · 보안 헤더)

**NFR-02 는 주장이 아니라 브라우저가 보증하는 사실이다.** `SecurityConfig` 가 내려보낸다.

| 헤더 | 값 | 왜 |
|---|---|---|
| `Content-Security-Policy` | `connect-src 'none'` 외 | **fetch·XHR·WebSocket·sendBeacon 원천 차단.** 우리가 실수로 요청 코드를 넣어도 브라우저가 막는다 |
| | `font-src 'self'` | 아이콘 폰트를 직접 서빙하므로 외부 폰트 CDN 이 필요 없다 |
| | `img-src 'self' data: blob:` | 외부 출처를 허용하던 이유(`/og-preview` 의 og:image)가 사라져 자기 출처만 남겼다 |
| | `style-src 'unsafe-inline'` | React 가 인라인 style 을 쓴다. 스타일은 데이터를 밖으로 못 보내므로 NFR-02 를 해치지 않는다 |
| | `worker-src 'self' blob:` | 정규식 워커 |
| `X-Content-Type-Options` | `nosniff` | 선언한 타입을 브라우저가 다시 추측하지 않게 |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | 도구 URL 자체가 의도를 드러낸다(`/jwt` 등) |
| `Permissions-Policy` | 카메라·마이크·위치 등 `()` | 쓰지 않는 권한은 닫아 둔다 |
| `Strict-Transport-Security` | 1년 · 하위도메인 | HTTPS 에서만 나간다(로컬 HTTP 에는 안 붙는 게 정상) |
| `X-Frame-Options` | `SAMEORIGIN` | 클릭재킹 |

### 아이콘 폰트를 직접 담는 이유

전에는 `fonts.googleapis.com` 에서 Material Icons 를 받아왔다. 그러면 **도구를 하나도 쓰지 않아도
첫 진입만으로 모든 방문자의 IP·User-Agent 가 구글에 남는다** — "서버로 아무것도 보내지 않는다" 를
내건 사이트에서 앞뒤가 맞지 않는다. 폰트를 `public/fonts/` 에 넣고(125KB) `font-src 'self'` 로 잠갔다.

### `dangerouslySetInnerHTML` 을 쓰는 곳

두 군데뿐이고 둘 다 입력 텍스트가 들어갈 경로가 없다.

- `/qr` — 숫자 좌표와 고정 색상만으로 만든 SVG
- 다이어그램 6종 — mermaid 가 `securityLevel: "strict"` 로 소독해 돌려준 SVG

## 8. 빌드 · 배포

```
npm run build             → frontend/dist/
gradlew copyFrontendBuild → src/main/resources/static/   ← 여기가 배포 대상
gradlew bootJar           → JAR 에 static 포함
```

> 🔴 **Docker 이미지 빌드에는 node 가 없다.** `build.gradle` 의 프론트 태스크는 `onlyIf { npmAvailable }`
> 가드라 전부 skip 되고, **커밋된 `static/` 을 그대로 패키징**한다.
> 배포 전 `./gradlew copyFrontendBuild` 를 빠뜨리면 **빌드는 성공하는데 사이트가 빈 화면**이 된다.

## 10. 보안 — 지킬 게 없다는 것이 설계다

- **화이트리스트 + `denyAll`** — 공개 경로를 명시하고 나머지는 전부 차단. 새 라우트 등록을 빠뜨리면 그 URL 만 403
- 무상태 — 세션·폼로그인·CSRF 표면 없음
- 인증·로그인 개념 자체가 없다. **보호할 사용자 데이터가 서버에 없기 때문**이다
- **오류 경계** — React 는 렌더 중 예외가 나면 트리 전체를 언마운트한다. 경계가 없으면 도구 하나의
  버그가 사이트 전체를 흰 화면으로 만든다. `ErrorBoundary` 가 `<Outlet>` 을 감싸 레이아웃은 살리고,
  `key={pathname}` 으로 다른 도구로 옮기면 초기화된다

## 11. 저장 기능이 필요해지면

지금 구조에서는 서버 저장이 불가능하다(DB·API 둘 다 없음). 필요해지면:

1. `04_미구현.md` §A-7 을 먼저 읽는다 — 이미 검토하고 보류한 항목이다
2. 도입한다면 `spring-boot-starter-data-jpa` + 드라이버를 추가하고 코드컨벤션 §5-2 를 따른다
   (로컬 = 인메모리 H2 휘발 / 운영 = 관리형 MySQL 영속)
3. **그 순간 "업로드 없음" 약속의 범위가 바뀐다** — `01_제품.md` §3 을 함께 고쳐야 한다
