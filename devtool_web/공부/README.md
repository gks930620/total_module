# 공부 — 이 도구들을 만들면서 알아야 했던 것들

이 폴더는 **설계 문서가 아니다.** [`../설계/`](../설계/README.md) 는 이 프로젝트가 무엇인지 설명하고,
여기는 **그걸 만들려면 알아야 하는 배경**을 적는다. 다른 프로젝트에 가도 그대로 쓰이는 내용이다.

각 문서는 이렇게 짰다.

- **왜 그런지부터** 적는다. 규칙만 외우면 처음 보는 상황에서 못 쓴다.
- **틀리는 지점**을 같이 적는다. 맞는 설명보다 "여기서 사람들이 넘어진다"가 더 오래 남는다.
- 이 프로젝트의 **어느 도구·어느 코드**와 이어지는지 표시한다. 손으로 만져 본 것이 기억에 남는다.
- **Spring / Java 백엔드 관점**을 같이 적는다. 브라우저 쪽만 알면 반쪽이다.

**읽는 순서에 정답은 없다.** 실무에서 자주 발목을 잡는 건 01(DB)과 05(웹 보안)다.
02는 "왜 이 한글이 깨지지" 를 만났을 때 찾아 읽으면 된다.
06은 다른 문서와 결이 다르다 — 암호는 자세히 적을수록 오히려 이해가 어려워서,
**막히는 두 지점만** 짧게 남겼다(JWT 비밀키 · 해시에 키가 왜 필요한가).

## 이 문서들을 믿어도 되는 정도

- 코드 예시와 계산은 **실제로 돌려 확인**했다. 값이 적혀 있으면 그 값이 나온다.
- 버전에 따라 달라지는 건 **어느 버전 기준인지** 적었다(MySQL 8 · PostgreSQL 16 · Java 17 · Spring Boot 3).
- 다만 이건 교과서가 아니라 **작업하며 정리한 메모**다. 중요한 결정 앞에서는 공식 문서를 한 번 더 본다.
  각 문서 끝에 1차 출처를 걸어 뒀다.
