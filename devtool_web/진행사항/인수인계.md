# 인수인계 — 이 저장소를 이어받는 AI 에게

이 프로젝트는 배포용 저장소로 옮겨지는 중이다. 이 문서는 **이어받는 쪽이 30분 안에
전체 그림을 잡도록** 쓴다. 여기 적힌 수치는 전부 2026-08-28 에 실측한 값이다 —
믿지 말고 아래 검증 명령으로 다시 세라(이 저장소의 규칙이기도 하다).

## 0. 읽는 순서

1. **루트 `README.md`** — 제품이 무엇인지, 일하는 규칙(TDD·등록 5곳·걷어내기 5곳). 전부 여기 있다
2. `설계/README.md` → `설계/03_도구카탈로그.md` — 도구 37종 전수
3. `진행사항/다음_할일.md` — 남은 관문(QA)과 배포 절차
4. 다이어그램을 만질 거면 `설계/05_다이어그램.md` — 그리기 편집기 구조 포함

## 2. 옮길 때 빠뜨리면 안 되는 것

- **`src/main/resources/static/` 산출물이 커밋에 포함**돼야 한다. Docker 이미지에 node 가 없어
  프론트를 빌드하지 못한다 — 산출물이 빠지면 빌드는 성공하는데 사이트가 빈 화면이다.
  프론트를 고쳤으면 항상 `./gradlew copyFrontendBuild` 후 커밋.
- `.claude/` 는 **옮기지 않아도 된다** — 이어받는 쪽에 필요한 내용은 전부 밖으로 옮겨 뒀다:
  제품·규칙 → 루트 `README.md`, 코드 컨벤션 → `설계/06_코드컨벤션.md`,
  배포 절차 → `설계/07_배포_Railway.md`.
- `설계/` `진행사항/` `공부/` 문서 폴더.
- git 히스토리 — 커밋 메시지가 "왜 이렇게 했나" 를 들고 있다. 파일 복사가 아니라
  저장소째 옮기는 쪽(remote 추가 후 push)을 권한다.

## 3. 이 저장소에서 일할 때 부딪히는 것들

README 의 규칙에 더해, 실제로 자주 걸리는 지점만:

- **CSP `connect-src 'none'`** — fetch·XHR 이 브라우저 차원에서 차단된다. "예시 파일을 fetch 로
  읽어오자" 같은 접근은 전부 불가능하다. 예시 이미지·PDF 는 그래서 캔버스/pdf-lib 으로
  **그 자리에서 만든다**(`lib/sampleFiles.js` · `pdfTools.makeSamplePdf`). 이 제약은 완화하면 안 된다 —
  "입력이 서버로 가지 않는다" 를 브라우저가 보증하게 만드는 장치다.
- **React Compiler 린트가 엄격하다** — 렌더 중 `Date.now()`·ref 읽기·컴포넌트 생성이 전부 오류다.
  현재 시각은 이벤트 핸들러에서 잡고, 파생 상태는 초기값/이벤트로 처리한다(TimestampPage ·
  CanvasEditor 에 선례가 있다).
- **도구 화면의 공통 패턴** — 페이지마다 `const GUIDE = {...}` + `<ToolGuide {...GUIDE} />` 가
  하단 사용법(화면 그림·입출력 예시·설명)이다. 예시 값은 지어내지 말고 **lib 함수를 실제로 돌려
  나온 값**을 적는다. 배치 원칙은 "넣는 것은 왼쪽·나온 것은 오른쪽", 기능이 둘이면 JWT 처럼 탭.
- **색은 토큰만** — 새 컴포넌트에서 `#hex` 를 쓰고 싶어지면 토큰을 늘린다. 읽는 면의 경계는
  `--edge`, 캔버스 편집기 안은 `--cv-line`/`--cv-dot`. 유일한 예외는 **내보내기 파일**
  (`exportSvg.js` · `sequence.js`) — 사이트 밖에서 열리므로 실색을 박는다.
- **localStorage** — `dtb.settings`·`dtb.schema_version`(설정, `lib/storage.js`) 와
  `dtb.canvas.<종류>`(그리기 문서 자동 저장). 도구 입력 원문은 어떤 것도 저장하지 않는다.

## 4. 이번 전수 점검에서 내린 결정들 (코드만 봐서는 안 보이는 것)

- **하단 FAQ → 사용법(ToolGuide)** — "이런 걸 묻겠지" 를 지어내는 FAQ 를 걷어내고
  검증 가능한 것(화면 그림·실제 입출력 값)만 남겼다. 새 도구도 이 형식을 따른다.
- **도구 9종 삭제** (46→37) — 비밀번호·마스킹(이전), http-status · slug · og-preview ·
  생활업무 6종(이번). og-preview 를 걷어내며 **유일한 외부 요청이 사라져** CSP `img-src` 도
  자기 출처로 조였다. 되살리려면 `img-src` 부터 다시 열어야 한다.
- **`/image-privacy` 에는 예시가 없다** — 일부러다. EXIF·GPS 데모에는 실사진 바이트가 필요한데
  fetch 가 막혀 있어 base64 를 소스에 박는 방법뿐이고, 청크가 사진 크기만큼 커진다. 사용자가
  "예시 없이 두자" 로 결정했다.
- **다이어그램 그리기 편집기** (`lib/canvas/` + `components/canvas/`) — 외부 라이브러리 없이
  직접 만들었다. React Flow 를 안 쓴 이유: "외부 런타임 의존성은 pdf-lib·mermaid 둘뿐" 이라는
  구조적 약속. 모든 조작이 "문서 → 새 문서" 순수 함수라 실행취소가 이력 쌓기로 끝난다.
  화면과 내보내기가 `geometry.js` 의 같은 기하를 쓴다 — 렌더러를 두 벌 만들면 어긋난다.
- **시퀀스만 편집기가 다르다** — 좌표가 없고 순서가 곧 배치라, 캔버스 대신 목록 편집이다.
- **의도적으로 남긴 "안 쓰는" lib 함수** — `dedupeLines`, `sortLines 의 natural 옵션`,
  `diffStats`, `parseNumber(v, 36)` 등은 화면에서 빠졌지만 테스트가 잠근 일반 API 라 남겼다.
  죽은 코드로 오인해 지우지 말 것 (지우려면 테스트와 함께, 사용자 확인 후).

## 5. 알려진 열린 항목 (이어받으면 여기부터)

1. **QA 미실시** — 유일하게 남은 완료 조건. `진행사항/다음_할일.md` 1순위 참조.
   특히 **그리기 편집기는 자동 테스트가 모델만 덮는다** — 드래그·연결 같은 포인터 상호작용은
   사람 손이 닿은 적이 없다.
2. **NFR-01 미검증** — 5MB/20MB JSON 성능 실측을 한 번도 안 했다.
3. `/cidr` 프리셋 칩에 켜짐 표시가 없다 — `/regex`·`/cron` 과 같은 방식(현재 값에서 유도)으로
   맞추면 된다. 사소해서 미룸.
4. `npm audit` high 2건(react-router-dom) — SSR/RSC 전용 경로라 이 앱(순수 CSR)은 해당 없음.
   해소는 breaking major 업그레이드 필요라 보류. **`npm audit fix --omit=dev` 는 금지**
   (devDependencies 가 지워져 빌드가 깨진다).
5. 배포 후 도메인이 정해지면 `sitemap.xml` `<loc>` 42개와 `robots.txt` 를 절대 URL 로 치환.
