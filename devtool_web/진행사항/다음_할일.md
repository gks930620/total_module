## 백로그 — 결정만 하면 🤖 가 만든다

전체 검토는 `설계/04_미구현.md` 의 A~E 분류에 있다. 여기는 **바로 착수 가능한 것**만.

| 후보 | 무게 | 비고 |
|---|---|---|
| SQL 포매터 + 파라미터 바인딩 | 외부 의존 0 | JPA 로그의 `?` 에 값을 끼워 실행 가능한 SQL 로. 실무 가치 큼 |
| 환경변수 ↔ properties ↔ yaml | 외부 의존 0 | `/yaml` 확장 |
| JSONPath / jq 스타일 질의 | 외부 의존 0 | `/json` 검색 확장 |
| 이미지 자르기 · 워터마크 | 외부 의존 0 | `/image` 에 이어붙임 |
| PDF 텍스트 추출 | pdf.js ~90KB(동적) | 스캔 PDF 는 불가(OCR 영역) |
| ZIP 압축·해제 | jszip ~30KB | 한글 파일명 CP949 처리가 관건 |
| 엑셀(XLSX) ↔ CSV/JSON | SheetJS ~150KB(동적) | `/csv` 에 "엑셀 열기" 로 |
| Markdown 미리보기 | ~20KB + DOMPurify | **XSS 살균 필수** |
| OCR | 한국어 데이터 ~15MB(동적) | 무거운 것 중 1순위 |
| 공휴일 반영 영업일 계산 | 정적 JSON | **매년 갱신 약속** 필요 — 안 하면 조용히 틀린다 |

**영구 배제**: 오피스↔PDF 변환 · PDF→Word · 맞춤법 검사 · 단축 URL · 내 IP · 속도 측정 ·
회원가입/저장 · 광고 · JWT 서명 검증 · 주민번호 생성 (사유는 07 문서 A·B·D 분류)

## 기술 메모

- **번들**: 첫 진입 gzip 72.8KB(JS 63.5 + CSS 9.3) / 상한 200KB. 도구를 더 늘려도 여유가 있다.
- ⚠️ **Vite 개발 서버가 떠 있으면 `./gradlew test` 가 EPERM 으로 실패한다**(`npm ci` 가 잠긴 파일을 못 지움).
  개발 서버를 끄거나 `-x frontendInstall -x frontendBuild -x copyFrontendBuild -x cleanFrontendStatic`.
- ⚠️ **`npm audit fix --omit=dev` 금지** — devDependencies(vite·vitest)를 지워 빌드가 통째로 깨진다.
- ⚠️ `npm audit` high 2건(react-router-dom) 잔존 — 전부 **SSR/RSC 전용 경로**라 순수 CSR 인 이 앱은 해당 없음.
  해소하려면 breaking major 업그레이드가 필요해 보류.
